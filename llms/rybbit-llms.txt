  - **Guides**
  - [Automated Weekly Report](/docs/api/weekly-report): Combine the overview and metric endpoints into a scheduled digest that summarizes last week's traffic, the week-over-week change, and your top pages and traffic sources.
  - [Find Where Users Drop Off](/docs/api/funnel-dropoff): Chain the funnel analysis and journeys endpoints to locate the biggest leak in a conversion flow, then discover where the users who abandon actually go instead.
  - [Compare Channel Performance](/docs/api/channel-performance): Rank your acquisition channels by how well they convert — not just how much traffic they send — by combining the metric, overview, and goals endpoints with channel filters.
  - [Build a Live Visitor Feed](/docs/api/live-feed): Poll the live visitor count and the events endpoint to build a real-time activity stream — the foundation for a live dashboard, an internal "who's online" widget, or an alert when a key page gets traffic.

  - **Endpoints**
  - [Sending Events](/docs/api/sending-events): Track pageviews, custom events, performance, and errors from any platform using the HTTP API.
  - Overview
    - [Get Overview](/docs/api/overview/overview): Returns high-level analytics metrics for a site.
    - [Get Overview (Time Series)](/docs/api/overview/time-series): Returns time-series analytics data broken down by configurable time buckets. Useful for charting trends over time.
    - [Get Metric](/docs/api/overview/metric): Returns dimensional analytics data broken down by a specific parameter. Supports pagination.
    - [Get Page Titles](/docs/api/overview/page-titles): Returns page-view metrics aggregated by HTML page title.
    - [Get Live Visitors](/docs/api/overview/live-visitors): Returns the count of unique active visitors within the specified time window. Useful for displaying real-time visitor counts.
  - Sessions
    - [Get Sessions](/docs/api/sessions/list): Returns a paginated list of sessions with their analytics data.
    - [Get Session](/docs/api/sessions/get): Returns detailed information about a specific session including all events and pageviews.
    - [Get Session Locations](/docs/api/sessions/locations): Returns aggregated session locations with coordinates for map visualization.
  - Session Replay
    - [Get Session Replays](/docs/api/session-replay/list): Returns recorded session replays with metadata, newest first.
    - [Get Session Replay Events](/docs/api/session-replay/events): Returns the rrweb events and metadata needed to reconstruct a session replay.
    - [Delete Session Replay](/docs/api/session-replay/delete): Permanently deletes a session replay recording. Requires site write access.
  - Users
    - [Get Users](/docs/api/users/list): Returns a paginated list of users with their analytics data. Supports filtering by identified users only.
    - [Get User Session Count](/docs/api/users/session-count): Returns the number of sessions per day for a specific user. Useful for visualizing user engagement over time.
    - [Get User Info](/docs/api/users/info): Returns detailed information about a specific user, including their profile traits and linked devices.
  - User Traits
    - [Get User Trait Keys](/docs/api/user-traits/keys): Returns the known user trait keys with the number of users that have each.
    - [Get User Trait Values](/docs/api/user-traits/values): Returns the distinct values for a given trait key, with user counts.
    - [Get Users by Trait](/docs/api/user-traits/users): Returns users matching a specific trait key and value, with location and session metadata.
  - Events
    - [Get Events](/docs/api/events/list): Returns a paginated list of events (pageviews, custom events, and outbound clicks).
    - [Get Event Names](/docs/api/events/names): Returns a list of unique custom event names with their occurrence counts.
    - [Get Event Time Series](/docs/api/events/time-series): Returns time-bucketed counts for the top custom events.
    - [Get Event Counts](/docs/api/events/count): Returns time-bucketed event counts grouped by event type.
    - [Get Event Properties](/docs/api/events/properties): Returns property key-value pairs for a specific event name with their occurrence counts.
    - [Get Outbound Links](/docs/api/events/outbound): Returns a list of outbound link clicks with their occurrence counts.
  - Goals
    - [Get Goals](/docs/api/goals/list): Returns a paginated list of goals with their conversion metrics.
    - [Get Goal Time Series](/docs/api/goals/time-series): Returns goal conversions and conversion rate over time.
    - [Get Goal Sessions](/docs/api/goals/sessions): Returns sessions that completed a specific goal. Useful for analyzing the behavior of converting users.
    - [Create Goal](/docs/api/goals/create): Creates a new goal for tracking conversions.
    - [Update Goal](/docs/api/goals/update): Updates an existing goal.
    - [Delete Goal](/docs/api/goals/delete): Deletes a goal. This action cannot be undone.
  - Funnels
    - [Get Funnels](/docs/api/funnels/list): Returns all saved funnels for a site.
    - [Analyze Funnel](/docs/api/funnels/analyze): Analyzes a funnel and returns step-by-step conversion data. Sessions must complete steps in order (step 2 must occur after step 1, etc.).
    - [Get Funnel Step Sessions](/docs/api/funnels/step-sessions): Returns sessions that either reached or dropped off at a specific funnel step. Useful for analyzing user behavior at each stage.
    - [Create Funnel](/docs/api/funnels/create): Creates or updates a saved funnel. If `reportId` is provided, updates the existing funnel.
    - [Delete Funnel](/docs/api/funnels/delete): Deletes a saved funnel. This action cannot be undone.
  - Performance
    - [Get Performance Overview](/docs/api/performance/overview): Returns aggregate performance metrics with percentile breakdowns for all Core Web Vitals.
    - [Get Performance Time Series](/docs/api/performance/time-series): Returns performance metrics over time, broken down by configurable time buckets. Useful for charting performance trends.
    - [Get Performance by Dimension](/docs/api/performance/by-dimension): Returns performance metrics broken down by a specific dimension (page, country, browser, etc.). Useful for identifying performance issues on specific pages or for specific user segments.
  - Errors
    - [Get Error Names](/docs/api/errors/names): Returns a list of unique error messages with occurrence counts and affected session counts.
    - [Get Error Events](/docs/api/errors/events): Returns individual error occurrences for a specific error message, with full context including stack traces.
    - [Get Error Time Series](/docs/api/errors/time-series): Returns error occurrence counts over time for a specific error message. Useful for tracking error trends and identifying when issues started.
  - Bots
    - [Get Bot Overview](/docs/api/bots/overview): Returns aggregate bot-traffic metrics with a breakdown by detection layer.
    - [Get Bot Time Series](/docs/api/bots/time-series): Returns bot request counts over time.
    - [Get Bots by Dimension](/docs/api/bots/by-dimension): Returns bot requests broken down by a dimension.
  - Insights
    - [Get Retention](/docs/api/insights/retention): Returns cohort-based retention analysis data. Users are grouped into cohorts based on their first visit, and retention is tracked over subsequent time periods.
    - [Get Journeys](/docs/api/insights/journeys): Returns the most common page navigation paths (user journeys) within sessions. Useful for understanding how users navigate through your site.

  - **Management**
  - Organizations
    - [Get My Organizations](/docs/api/organizations/list): Returns all organizations the authenticated user is a member of, including all members for each organization. Excludes subscription and billing information. Supports both session cookies and API key (Bearer token) authentication.
    - [Get Organization Sites](/docs/api/organizations/sites): Returns all sites in an organization the caller can access, with usage and subscription info.
    - [Create Site](/docs/api/organizations/create-site): Creates a new site within an organization. Requires admin or owner role in the organization.
    - [Get Organization Members](/docs/api/organizations/members): Returns all members of an organization with their user details and roles. Requires membership in the organization.
    - [Add Organization Member](/docs/api/organizations/add-member): Adds a user to an organization with a specified role. The user must already exist in the system. Requires admin or owner role in the organization.
    - [Invite Member](/docs/api/organizations/invite-member): Send an organization invitation to a user by email.
    - [Remove Member](/docs/api/organizations/remove-member): Remove a member from an organization.
    - [Update Member Role](/docs/api/organizations/update-member-role): Change an organization member's role.
    - [Get Organization Event Count](/docs/api/organizations/event-count): Returns daily event usage counts across an organization's sites.
  - Teams
    - [Get Teams](/docs/api/teams/list): Returns the teams in an organization, with their members and accessible sites.
    - [Create Team](/docs/api/teams/create): Creates a team in an organization. Requires admin/owner role.
    - [Update Team](/docs/api/teams/update): Updates a team's name, members, or site access. Requires admin/owner role.
    - [Delete Team](/docs/api/teams/delete): Deletes a team. Requires admin/owner role.
  - Sites
    - [Get Site](/docs/api/sites/get): Returns detailed information about a specific site including its configuration.
    - [Get Site Has Data](/docs/api/sites/has-data): Returns whether the site has received any analytics events.
    - [Get Site Public Status](/docs/api/sites/is-public): Returns whether the site's analytics are publicly accessible.
    - [Delete Site](/docs/api/sites/delete): Permanently deletes a site and all its associated data. This action cannot be undone. Requires admin or owner role.
    - [Update Site Config](/docs/api/sites/update-config): Updates site configuration settings. All fields are optional - only include the fields you want to update. Requires admin or owner role.
    - [Get Excluded IPs](/docs/api/sites/excluded-ips): Returns the list of IP addresses and CIDR ranges that are excluded from tracking.
    - [Get Excluded Countries](/docs/api/sites/excluded-countries): Returns the list of country codes that are excluded from tracking.
    - [Get Excluded Paths](/docs/api/sites/excluded-paths): Returns the list of URL paths excluded from analytics.
    - [Get Excluded Hostnames](/docs/api/sites/excluded-hostnames): Returns the list of hostnames excluded from analytics.
    - [Get Excluded User Agents](/docs/api/sites/excluded-user-agents): Returns the list of user-agent patterns excluded from analytics.
    - [Get Private Link Config](/docs/api/sites/get-private-link): Returns the private link key configuration. Private links allow sharing analytics with a secret key without requiring authentication.
    - [Update Private Link Config](/docs/api/sites/update-private-link): Generates or revokes a private link key for sharing analytics without authentication. Requires admin or owner role.
    - [Export PDF Report](/docs/api/sites/export-pdf): Generates a downloadable PDF analytics report for a date range.
  - Imports
    - [List Imports](/docs/api/imports/list): Returns all data imports for a site with their progress counts.
    - [Create Import](/docs/api/imports/create): Starts a new data import from a supported platform.
    - [Upload Import Events](/docs/api/imports/events): Uploads a batch of raw events to an in-progress import.
    - [Delete Import](/docs/api/imports/delete): Deletes an import and all events it added. The import must be finished.
  - API Keys
    - [Create API Key](/docs/api/api-keys/create): Programmatically create a new API key for your account.
    - [Create Organization API Key](/docs/api/api-keys/create-org): Programmatically create an API key owned by an organization.
    - [List API Keys](/docs/api/api-keys/list): List the API keys for your account or organization.
    - [Update API Key](/docs/api/api-keys/update): Update an existing API key's name, enabled state, or expiry.
    - [Delete API Key](/docs/api/api-keys/delete): Revoke an API key by its id.

  - **Endpoints**
  - [Sending Events](/de/docs/api/sending-events): Track pageviews, custom events, performance, and errors from any platform using the HTTP API.
  - Overview
    - [Get Overview](/de/docs/api/overview/overview): Returns high-level analytics metrics for a site.
    - [Get Overview (Time Series)](/de/docs/api/overview/time-series): Returns time-series analytics data broken down by configurable time buckets. Useful for charting trends over time.
    - [Get Metric](/de/docs/api/overview/metric): Returns dimensional analytics data broken down by a specific parameter. Supports pagination.
    - [Get Page Titles](/de/docs/api/overview/page-titles): Returns page-view metrics aggregated by HTML page title.
    - [Get Live Visitors](/de/docs/api/overview/live-visitors): Returns the count of unique active visitors within the specified time window. Useful for displaying real-time visitor counts.
  - Sessions
    - [Get Sessions](/de/docs/api/sessions/list): Returns a paginated list of sessions with their analytics data.
    - [Get Session](/de/docs/api/sessions/get): Returns detailed information about a specific session including all events and pageviews.
    - [Get Session Locations](/de/docs/api/sessions/locations): Returns aggregated session locations with coordinates for map visualization.
  - Session Replay
    - [Get Session Replays](/de/docs/api/session-replay/list): Returns recorded session replays with metadata, newest first.
    - [Get Session Replay Events](/de/docs/api/session-replay/events): Returns the rrweb events and metadata needed to reconstruct a session replay.
    - [Delete Session Replay](/de/docs/api/session-replay/delete): Permanently deletes a session replay recording. Requires site write access.
  - Users
    - [Get Users](/de/docs/api/users/list): Returns a paginated list of users with their analytics data. Supports filtering by identified users only.
    - [Get User Session Count](/de/docs/api/users/session-count): Returns the number of sessions per day for a specific user. Useful for visualizing user engagement over time.
    - [Get User Info](/de/docs/api/users/info): Returns detailed information about a specific user, including their profile traits and linked devices.
  - User Traits
    - [Get User Trait Keys](/de/docs/api/user-traits/keys): Returns the known user trait keys with the number of users that have each.
    - [Get User Trait Values](/de/docs/api/user-traits/values): Returns the distinct values for a given trait key, with user counts.
    - [Get Users by Trait](/de/docs/api/user-traits/users): Returns users matching a specific trait key and value, with location and session metadata.
  - Events
    - [Get Events](/de/docs/api/events/list): Returns a paginated list of events (pageviews, custom events, and outbound clicks).
    - [Get Event Names](/de/docs/api/events/names): Returns a list of unique custom event names with their occurrence counts.
    - [Get Event Time Series](/de/docs/api/events/time-series): Returns time-bucketed counts for the top custom events.
    - [Get Event Counts](/de/docs/api/events/count): Returns time-bucketed event counts grouped by event type.
    - [Get Event Properties](/de/docs/api/events/properties): Returns property key-value pairs for a specific event name with their occurrence counts.
    - [Get Outbound Links](/de/docs/api/events/outbound): Returns a list of outbound link clicks with their occurrence counts.
  - Goals
    - [Get Goals](/de/docs/api/goals/list): Returns a paginated list of goals with their conversion metrics.
    - [Get Goal Time Series](/de/docs/api/goals/time-series): Returns goal conversions and conversion rate over time.
    - [Get Goal Sessions](/de/docs/api/goals/sessions): Returns sessions that completed a specific goal. Useful for analyzing the behavior of converting users.
    - [Create Goal](/de/docs/api/goals/create): Creates a new goal for tracking conversions.
    - [Update Goal](/de/docs/api/goals/update): Updates an existing goal.
    - [Delete Goal](/de/docs/api/goals/delete): Deletes a goal. This action cannot be undone.
  - Funnels
    - [Get Funnels](/de/docs/api/funnels/list): Returns all saved funnels for a site.
    - [Analyze Funnel](/de/docs/api/funnels/analyze): Analyzes a funnel and returns step-by-step conversion data. Sessions must complete steps in order (step 2 must occur after step 1, etc.).
    - [Get Funnel Step Sessions](/de/docs/api/funnels/step-sessions): Returns sessions that either reached or dropped off at a specific funnel step. Useful for analyzing user behavior at each stage.
    - [Create Funnel](/de/docs/api/funnels/create): Creates or updates a saved funnel. If `reportId` is provided, updates the existing funnel.
    - [Delete Funnel](/de/docs/api/funnels/delete): Deletes a saved funnel. This action cannot be undone.
  - Performance
    - [Get Performance Overview](/de/docs/api/performance/overview): Returns aggregate performance metrics with percentile breakdowns for all Core Web Vitals.
    - [Get Performance Time Series](/de/docs/api/performance/time-series): Returns performance metrics over time, broken down by configurable time buckets. Useful for charting performance trends.
    - [Get Performance by Dimension](/de/docs/api/performance/by-dimension): Returns performance metrics broken down by a specific dimension (page, country, browser, etc.). Useful for identifying performance issues on specific pages or for specific user segments.
  - Errors
    - [Get Error Names](/de/docs/api/errors/names): Returns a list of unique error messages with occurrence counts and affected session counts.
    - [Get Error Events](/de/docs/api/errors/events): Returns individual error occurrences for a specific error message, with full context including stack traces.
    - [Get Error Time Series](/de/docs/api/errors/time-series): Returns error occurrence counts over time for a specific error message. Useful for tracking error trends and identifying when issues started.
  - Bots
    - [Get Bot Overview](/de/docs/api/bots/overview): Returns aggregate bot-traffic metrics with a breakdown by detection layer.
    - [Get Bot Time Series](/de/docs/api/bots/time-series): Returns bot request counts over time.
    - [Get Bots by Dimension](/de/docs/api/bots/by-dimension): Returns bot requests broken down by a dimension.
  - Insights
    - [Get Retention](/de/docs/api/insights/retention): Returns cohort-based retention analysis data. Users are grouped into cohorts based on their first visit, and retention is tracked over subsequent time periods.
    - [Get Journeys](/de/docs/api/insights/journeys): Returns the most common page navigation paths (user journeys) within sessions. Useful for understanding how users navigate through your site.

    - [Remove Member](/de/docs/api/organizations/remove-member): Remove a member from an organization.

    - [Get Organization Event Count](/de/docs/api/organizations/event-count): Returns daily event usage counts across an organization's sites.
  - Teams
    - [Get Teams](/de/docs/api/teams/list): Returns the teams in an organization, with their members and accessible sites.
    - [Create Team](/de/docs/api/teams/create): Creates a team in an organization. Requires admin/owner role.
    - [Update Team](/de/docs/api/teams/update): Updates a team's name, members, or site access. Requires admin/owner role.
    - [Delete Team](/de/docs/api/teams/delete): Deletes a team. Requires admin/owner role.
  - Sites
    - [Get Site](/de/docs/api/sites/get): Returns detailed information about a specific site including its configuration.
    - [Get Site Has Data](/de/docs/api/sites/has-data): Returns whether the site has received any analytics events.
    - [Get Site Public Status](/de/docs/api/sites/is-public): Returns whether the site's analytics are publicly accessible.
    - [Delete Site](/de/docs/api/sites/delete): Permanently deletes a site and all its associated data. This action cannot be undone. Requires admin or owner role.
    - [Update Site Config](/de/docs/api/sites/update-config): Updates site configuration settings. All fields are optional - only include the fields you want to update. Requires admin or owner role.
    - [Get Excluded IPs](/de/docs/api/sites/excluded-ips): Returns the list of IP addresses and CIDR ranges that are excluded from tracking.
    - [Get Excluded Countries](/de/docs/api/sites/excluded-countries): Returns the list of country codes that are excluded from tracking.
    - [Get Excluded Paths](/de/docs/api/sites/excluded-paths): Returns the list of URL paths excluded from analytics.
    - [Get Excluded Hostnames](/de/docs/api/sites/excluded-hostnames): Returns the list of hostnames excluded from analytics.
    - [Get Excluded User Agents](/de/docs/api/sites/excluded-user-agents): Returns the list of user-agent patterns excluded from analytics.
    - [Get Private Link Config](/de/docs/api/sites/get-private-link): Returns the private link key configuration. Private links allow sharing analytics with a secret key without requiring authentication.
    - [Update Private Link Config](/de/docs/api/sites/update-private-link): Generates or revokes a private link key for sharing analytics without authentication. Requires admin or owner role.
    - [Export PDF Report](/de/docs/api/sites/export-pdf): Generates a downloadable PDF analytics report for a date range.
  - Imports
    - [List Imports](/de/docs/api/imports/list): Returns all data imports for a site with their progress counts.
    - [Create Import](/de/docs/api/imports/create): Starts a new data import from a supported platform.
    - [Upload Import Events](/de/docs/api/imports/events): Uploads a batch of raw events to an in-progress import.
    - [Delete Import](/de/docs/api/imports/delete): Deletes an import and all events it added. The import must be finished.

    - [Create API Key](/de/docs/api/api-keys/create): Programmatically create a new API key for your account.

  - **Endpoints**
  - [Sending Events](/fr/docs/api/sending-events): Track pageviews, custom events, performance, and errors from any platform using the HTTP API.
  - Overview
    - [Get Overview](/fr/docs/api/overview/overview): Returns high-level analytics metrics for a site.
    - [Get Overview (Time Series)](/fr/docs/api/overview/time-series): Returns time-series analytics data broken down by configurable time buckets. Useful for charting trends over time.
    - [Get Metric](/fr/docs/api/overview/metric): Returns dimensional analytics data broken down by a specific parameter. Supports pagination.
    - [Get Page Titles](/fr/docs/api/overview/page-titles): Returns page-view metrics aggregated by HTML page title.
    - [Get Live Visitors](/fr/docs/api/overview/live-visitors): Returns the count of unique active visitors within the specified time window. Useful for displaying real-time visitor counts.
  - Sessions
    - [Get Sessions](/fr/docs/api/sessions/list): Returns a paginated list of sessions with their analytics data.
    - [Get Session](/fr/docs/api/sessions/get): Returns detailed information about a specific session including all events and pageviews.
    - [Get Session Locations](/fr/docs/api/sessions/locations): Returns aggregated session locations with coordinates for map visualization.
  - Session Replay
    - [Get Session Replays](/fr/docs/api/session-replay/list): Returns recorded session replays with metadata, newest first.
    - [Get Session Replay Events](/fr/docs/api/session-replay/events): Returns the rrweb events and metadata needed to reconstruct a session replay.
    - [Delete Session Replay](/fr/docs/api/session-replay/delete): Permanently deletes a session replay recording. Requires site write access.
  - Users
    - [Get Users](/fr/docs/api/users/list): Returns a paginated list of users with their analytics data. Supports filtering by identified users only.
    - [Get User Session Count](/fr/docs/api/users/session-count): Returns the number of sessions per day for a specific user. Useful for visualizing user engagement over time.
    - [Get User Info](/fr/docs/api/users/info): Returns detailed information about a specific user, including their profile traits and linked devices.
  - User Traits
    - [Get User Trait Keys](/fr/docs/api/user-traits/keys): Returns the known user trait keys with the number of users that have each.
    - [Get User Trait Values](/fr/docs/api/user-traits/values): Returns the distinct values for a given trait key, with user counts.
    - [Get Users by Trait](/fr/docs/api/user-traits/users): Returns users matching a specific trait key and value, with location and session metadata.
  - Events
    - [Get Events](/fr/docs/api/events/list): Returns a paginated list of events (pageviews, custom events, and outbound clicks).
    - [Get Event Names](/fr/docs/api/events/names): Returns a list of unique custom event names with their occurrence counts.
    - [Get Event Time Series](/fr/docs/api/events/time-series): Returns time-bucketed counts for the top custom events.
    - [Get Event Counts](/fr/docs/api/events/count): Returns time-bucketed event counts grouped by event type.
    - [Get Event Properties](/fr/docs/api/events/properties): Returns property key-value pairs for a specific event name with their occurrence counts.
    - [Get Outbound Links](/fr/docs/api/events/outbound): Returns a list of outbound link clicks with their occurrence counts.
  - Goals
    - [Get Goals](/fr/docs/api/goals/list): Returns a paginated list of goals with their conversion metrics.
    - [Get Goal Time Series](/fr/docs/api/goals/time-series): Returns goal conversions and conversion rate over time.
    - [Get Goal Sessions](/fr/docs/api/goals/sessions): Returns sessions that completed a specific goal. Useful for analyzing the behavior of converting users.
    - [Create Goal](/fr/docs/api/goals/create): Creates a new goal for tracking conversions.
    - [Update Goal](/fr/docs/api/goals/update): Updates an existing goal.
    - [Delete Goal](/fr/docs/api/goals/delete): Deletes a goal. This action cannot be undone.
  - Funnels
    - [Get Funnels](/fr/docs/api/funnels/list): Returns all saved funnels for a site.
    - [Analyze Funnel](/fr/docs/api/funnels/analyze): Analyzes a funnel and returns step-by-step conversion data. Sessions must complete steps in order (step 2 must occur after step 1, etc.).
    - [Get Funnel Step Sessions](/fr/docs/api/funnels/step-sessions): Returns sessions that either reached or dropped off at a specific funnel step. Useful for analyzing user behavior at each stage.
    - [Create Funnel](/fr/docs/api/funnels/create): Creates or updates a saved funnel. If `reportId` is provided, updates the existing funnel.
    - [Delete Funnel](/fr/docs/api/funnels/delete): Deletes a saved funnel. This action cannot be undone.
  - Performance
    - [Get Performance Overview](/fr/docs/api/performance/overview): Returns aggregate performance metrics with percentile breakdowns for all Core Web Vitals.
    - [Get Performance Time Series](/fr/docs/api/performance/time-series): Returns performance metrics over time, broken down by configurable time buckets. Useful for charting performance trends.
    - [Get Performance by Dimension](/fr/docs/api/performance/by-dimension): Returns performance metrics broken down by a specific dimension (page, country, browser, etc.). Useful for identifying performance issues on specific pages or for specific user segments.
  - Errors
    - [Get Error Names](/fr/docs/api/errors/names): Returns a list of unique error messages with occurrence counts and affected session counts.
    - [Get Error Events](/fr/docs/api/errors/events): Returns individual error occurrences for a specific error message, with full context including stack traces.
    - [Get Error Time Series](/fr/docs/api/errors/time-series): Returns error occurrence counts over time for a specific error message. Useful for tracking error trends and identifying when issues started.
  - Bots
    - [Get Bot Overview](/fr/docs/api/bots/overview): Returns aggregate bot-traffic metrics with a breakdown by detection layer.
    - [Get Bot Time Series](/fr/docs/api/bots/time-series): Returns bot request counts over time.
    - [Get Bots by Dimension](/fr/docs/api/bots/by-dimension): Returns bot requests broken down by a dimension.
  - Insights
    - [Get Retention](/fr/docs/api/insights/retention): Returns cohort-based retention analysis data. Users are grouped into cohorts based on their first visit, and retention is tracked over subsequent time periods.
    - [Get Journeys](/fr/docs/api/insights/journeys): Returns the most common page navigation paths (user journeys) within sessions. Useful for understanding how users navigate through your site.

  - **Management**
  - Organizations
    - [Get My Organizations](/fr/docs/api/organizations/list): Returns all organizations the authenticated user is a member of, including all members for each organization. Excludes subscription and billing information. Supports both session cookies and API key (Bearer token) authentication.
    - [Get Organization Sites](/fr/docs/api/organizations/sites): Returns all sites in an organization the caller can access, with usage and subscription info.
    - [Create Site](/fr/docs/api/organizations/create-site): Creates a new site within an organization. Requires admin or owner role in the organization.
    - [Get Organization Members](/fr/docs/api/organizations/members): Returns all members of an organization with their user details and roles. Requires membership in the organization.
    - [Add Organization Member](/fr/docs/api/organizations/add-member): Adds a user to an organization with a specified role. The user must already exist in the system. Requires admin or owner role in the organization.
    - [Invite Member](/fr/docs/api/organizations/invite-member): Send an organization invitation to a user by email.
    - [Remove Member](/fr/docs/api/organizations/remove-member): Remove a member from an organization.
    - [Update Member Role](/fr/docs/api/organizations/update-member-role): Change an organization member's role.
    - [Get Organization Event Count](/fr/docs/api/organizations/event-count): Returns daily event usage counts across an organization's sites.
  - Teams
    - [Get Teams](/fr/docs/api/teams/list): Returns the teams in an organization, with their members and accessible sites.
    - [Create Team](/fr/docs/api/teams/create): Creates a team in an organization. Requires admin/owner role.
    - [Update Team](/fr/docs/api/teams/update): Updates a team's name, members, or site access. Requires admin/owner role.
    - [Delete Team](/fr/docs/api/teams/delete): Deletes a team. Requires admin/owner role.
  - Sites
    - [Get Site](/fr/docs/api/sites/get): Returns detailed information about a specific site including its configuration.
    - [Get Site Has Data](/fr/docs/api/sites/has-data): Returns whether the site has received any analytics events.
    - [Get Site Public Status](/fr/docs/api/sites/is-public): Returns whether the site's analytics are publicly accessible.
    - [Delete Site](/fr/docs/api/sites/delete): Permanently deletes a site and all its associated data. This action cannot be undone. Requires admin or owner role.
    - [Update Site Config](/fr/docs/api/sites/update-config): Updates site configuration settings. All fields are optional - only include the fields you want to update. Requires admin or owner role.
    - [Get Excluded IPs](/fr/docs/api/sites/excluded-ips): Returns the list of IP addresses and CIDR ranges that are excluded from tracking.
    - [Get Excluded Countries](/fr/docs/api/sites/excluded-countries): Returns the list of country codes that are excluded from tracking.
    - [Get Excluded Paths](/fr/docs/api/sites/excluded-paths): Returns the list of URL paths excluded from analytics.
    - [Get Excluded Hostnames](/fr/docs/api/sites/excluded-hostnames): Returns the list of hostnames excluded from analytics.
    - [Get Excluded User Agents](/fr/docs/api/sites/excluded-user-agents): Returns the list of user-agent patterns excluded from analytics.
    - [Get Private Link Config](/fr/docs/api/sites/get-private-link): Returns the private link key configuration. Private links allow sharing analytics with a secret key without requiring authentication.
    - [Update Private Link Config](/fr/docs/api/sites/update-private-link): Generates or revokes a private link key for sharing analytics without authentication. Requires admin or owner role.
    - [Export PDF Report](/fr/docs/api/sites/export-pdf): Generates a downloadable PDF analytics report for a date range.
  - Imports
    - [List Imports](/fr/docs/api/imports/list): Returns all data imports for a site with their progress counts.
    - [Create Import](/fr/docs/api/imports/create): Starts a new data import from a supported platform.
    - [Upload Import Events](/fr/docs/api/imports/events): Uploads a batch of raw events to an in-progress import.
    - [Delete Import](/fr/docs/api/imports/delete): Deletes an import and all events it added. The import must be finished.
  - API Keys
    - [Create API Key](/fr/docs/api/api-keys/create): Programmatically create a new API key for your account.
    - [Create Organization API Key](/fr/docs/api/api-keys/create-org): Programmatically create an API key owned by an organization.
    - [List API Keys](/fr/docs/api/api-keys/list): List the API keys for your account or organization.
    - [Update API Key](/fr/docs/api/api-keys/update): Update an existing API key's name, enabled state, or expiry.
    - [Delete API Key](/fr/docs/api/api-keys/delete): Revoke an API key by its id.

    - [Get Metric](/zh/docs/api/overview/metric): Returns dimensional analytics data broken down by a specific parameter. Supports pagination.
    - [Get Page Titles](/zh/docs/api/overview/page-titles): Returns page-view metrics aggregated by HTML page title.

  - Sessions

    - [Get User Info](/zh/docs/api/users/info): Returns detailed information about a specific user, including their profile traits and linked devices.

    - [Get Event Properties](/zh/docs/api/events/properties): Returns property key-value pairs for a specific event name with their occurrence counts.

    - [Delete Goal](/zh/docs/api/goals/delete): Deletes a goal. This action cannot be undone.

  - **Guides**
  - [Automated Weekly Report](/ko/docs/api/weekly-report): Combine the overview and metric endpoints into a scheduled digest that summarizes last week's traffic, the week-over-week change, and your top pages and traffic sources.
  - [Find Where Users Drop Off](/ko/docs/api/funnel-dropoff): Chain the funnel analysis and journeys endpoints to locate the biggest leak in a conversion flow, then discover where the users who abandon actually go instead.
  - [Compare Channel Performance](/ko/docs/api/channel-performance): Rank your acquisition channels by how well they convert — not just how much traffic they send — by combining the metric, overview, and goals endpoints with channel filters.
  - [Build a Live Visitor Feed](/ko/docs/api/live-feed): Poll the live visitor count and the events endpoint to build a real-time activity stream — the foundation for a live dashboard, an internal "who's online" widget, or an alert when a key page gets traffic.

  - **Endpoints**
  - [Sending Events](/ko/docs/api/sending-events): Track pageviews, custom events, performance, and errors from any platform using the HTTP API.
  - Overview
    - [Get Overview](/ko/docs/api/overview/overview): Returns high-level analytics metrics for a site.
    - [Get Overview (Time Series)](/ko/docs/api/overview/time-series): Returns time-series analytics data broken down by configurable time buckets. Useful for charting trends over time.
    - [Get Metric](/ko/docs/api/overview/metric): Returns dimensional analytics data broken down by a specific parameter. Supports pagination.
    - [Get Page Titles](/ko/docs/api/overview/page-titles): Returns page-view metrics aggregated by HTML page title.
    - [Get Live Visitors](/ko/docs/api/overview/live-visitors): Returns the count of unique active visitors within the specified time window. Useful for displaying real-time visitor counts.
  - Sessions
    - [Get Sessions](/ko/docs/api/sessions/list): Returns a paginated list of sessions with their analytics data.
    - [Get Session](/ko/docs/api/sessions/get): Returns detailed information about a specific session including all events and pageviews.
    - [Get Session Locations](/ko/docs/api/sessions/locations): Returns aggregated session locations with coordinates for map visualization.
  - Session Replay
    - [Get Session Replays](/ko/docs/api/session-replay/list): Returns recorded session replays with metadata, newest first.
    - [Get Session Replay Events](/ko/docs/api/session-replay/events): Returns the rrweb events and metadata needed to reconstruct a session replay.
    - [Delete Session Replay](/ko/docs/api/session-replay/delete): Permanently deletes a session replay recording. Requires site write access.
  - Users
    - [Get Users](/ko/docs/api/users/list): Returns a paginated list of users with their analytics data. Supports filtering by identified users only.
    - [Get User Session Count](/ko/docs/api/users/session-count): Returns the number of sessions per day for a specific user. Useful for visualizing user engagement over time.
    - [Get User Info](/ko/docs/api/users/info): Returns detailed information about a specific user, including their profile traits and linked devices.
  - User Traits
    - [Get User Trait Keys](/ko/docs/api/user-traits/keys): Returns the known user trait keys with the number of users that have each.
    - [Get User Trait Values](/ko/docs/api/user-traits/values): Returns the distinct values for a given trait key, with user counts.
    - [Get Users by Trait](/ko/docs/api/user-traits/users): Returns users matching a specific trait key and value, with location and session metadata.
  - Events
    - [Get Events](/ko/docs/api/events/list): Returns a paginated list of events (pageviews, custom events, and outbound clicks).
    - [Get Event Names](/ko/docs/api/events/names): Returns a list of unique custom event names with their occurrence counts.
    - [Get Event Time Series](/ko/docs/api/events/time-series): Returns time-bucketed counts for the top custom events.
    - [Get Event Counts](/ko/docs/api/events/count): Returns time-bucketed event counts grouped by event type.
    - [Get Event Properties](/ko/docs/api/events/properties): Returns property key-value pairs for a specific event name with their occurrence counts.
    - [Get Outbound Links](/ko/docs/api/events/outbound): Returns a list of outbound link clicks with their occurrence counts.
  - Goals
    - [Get Goals](/ko/docs/api/goals/list): Returns a paginated list of goals with their conversion metrics.
    - [Get Goal Time Series](/ko/docs/api/goals/time-series): Returns goal conversions and conversion rate over time.
    - [Get Goal Sessions](/ko/docs/api/goals/sessions): Returns sessions that completed a specific goal. Useful for analyzing the behavior of converting users.
    - [Create Goal](/ko/docs/api/goals/create): Creates a new goal for tracking conversions.
    - [Update Goal](/ko/docs/api/goals/update): Updates an existing goal.
    - [Delete Goal](/ko/docs/api/goals/delete): Deletes a goal. This action cannot be undone.
  - Funnels
    - [Get Funnels](/ko/docs/api/funnels/list): Returns all saved funnels for a site.
    - [Analyze Funnel](/ko/docs/api/funnels/analyze): Analyzes a funnel and returns step-by-step conversion data. Sessions must complete steps in order (step 2 must occur after step 1, etc.).
    - [Get Funnel Step Sessions](/ko/docs/api/funnels/step-sessions): Returns sessions that either reached or dropped off at a specific funnel step. Useful for analyzing user behavior at each stage.
    - [Create Funnel](/ko/docs/api/funnels/create): Creates or updates a saved funnel. If `reportId` is provided, updates the existing funnel.
    - [Delete Funnel](/ko/docs/api/funnels/delete): Deletes a saved funnel. This action cannot be undone.
  - Performance
    - [Get Performance Overview](/ko/docs/api/performance/overview): Returns aggregate performance metrics with percentile breakdowns for all Core Web Vitals.
    - [Get Performance Time Series](/ko/docs/api/performance/time-series): Returns performance metrics over time, broken down by configurable time buckets. Useful for charting performance trends.
    - [Get Performance by Dimension](/ko/docs/api/performance/by-dimension): Returns performance metrics broken down by a specific dimension (page, country, browser, etc.). Useful for identifying performance issues on specific pages or for specific user segments.
  - Errors
    - [Get Error Names](/ko/docs/api/errors/names): Returns a list of unique error messages with occurrence counts and affected session counts.
    - [Get Error Events](/ko/docs/api/errors/events): Returns individual error occurrences for a specific error message, with full context including stack traces.
    - [Get Error Time Series](/ko/docs/api/errors/time-series): Returns error occurrence counts over time for a specific error message. Useful for tracking error trends and identifying when issues started.
  - Bots
    - [Get Bot Overview](/ko/docs/api/bots/overview): Returns aggregate bot-traffic metrics with a breakdown by detection layer.
    - [Get Bot Time Series](/ko/docs/api/bots/time-series): Returns bot request counts over time.
    - [Get Bots by Dimension](/ko/docs/api/bots/by-dimension): Returns bot requests broken down by a dimension.
  - Insights
    - [Get Retention](/ko/docs/api/insights/retention): Returns cohort-based retention analysis data. Users are grouped into cohorts based on their first visit, and retention is tracked over subsequent time periods.
    - [Get Journeys](/ko/docs/api/insights/journeys): Returns the most common page navigation paths (user journeys) within sessions. Useful for understanding how users navigate through your site.

  - **Management**
  - Organizations
    - [Get My Organizations](/ko/docs/api/organizations/list): Returns all organizations the authenticated user is a member of, including all members for each organization. Excludes subscription and billing information. Supports both session cookies and API key (Bearer token) authentication.
    - [Get Organization Sites](/ko/docs/api/organizations/sites): Returns all sites in an organization the caller can access, with usage and subscription info.
    - [Create Site](/ko/docs/api/organizations/create-site): Creates a new site within an organization. Requires admin or owner role in the organization.
    - [Get Organization Members](/ko/docs/api/organizations/members): Returns all members of an organization with their user details and roles. Requires membership in the organization.
    - [Add Organization Member](/ko/docs/api/organizations/add-member): Adds a user to an organization with a specified role. The user must already exist in the system. Requires admin or owner role in the organization.
    - [Invite Member](/ko/docs/api/organizations/invite-member): Send an organization invitation to a user by email.
    - [Remove Member](/ko/docs/api/organizations/remove-member): Remove a member from an organization.
    - [Update Member Role](/ko/docs/api/organizations/update-member-role): Change an organization member's role.
    - [Get Organization Event Count](/ko/docs/api/organizations/event-count): Returns daily event usage counts across an organization's sites.
  - Teams
    - [Get Teams](/ko/docs/api/teams/list): Returns the teams in an organization, with their members and accessible sites.
    - [Create Team](/ko/docs/api/teams/create): Creates a team in an organization. Requires admin/owner role.
    - [Update Team](/ko/docs/api/teams/update): Updates a team's name, members, or site access. Requires admin/owner role.
    - [Delete Team](/ko/docs/api/teams/delete): Deletes a team. Requires admin/owner role.
  - Sites
    - [Get Site](/ko/docs/api/sites/get): Returns detailed information about a specific site including its configuration.
    - [Get Site Has Data](/ko/docs/api/sites/has-data): Returns whether the site has received any analytics events.
    - [Get Site Public Status](/ko/docs/api/sites/is-public): Returns whether the site's analytics are publicly accessible.
    - [Delete Site](/ko/docs/api/sites/delete): Permanently deletes a site and all its associated data. This action cannot be undone. Requires admin or owner role.
    - [Update Site Config](/ko/docs/api/sites/update-config): Updates site configuration settings. All fields are optional - only include the fields you want to update. Requires admin or owner role.
    - [Get Excluded IPs](/ko/docs/api/sites/excluded-ips): Returns the list of IP addresses and CIDR ranges that are excluded from tracking.
    - [Get Excluded Countries](/ko/docs/api/sites/excluded-countries): Returns the list of country codes that are excluded from tracking.
    - [Get Excluded Paths](/ko/docs/api/sites/excluded-paths): Returns the list of URL paths excluded from analytics.
    - [Get Excluded Hostnames](/ko/docs/api/sites/excluded-hostnames): Returns the list of hostnames excluded from analytics.
    - [Get Excluded User Agents](/ko/docs/api/sites/excluded-user-agents): Returns the list of user-agent patterns excluded from analytics.
    - [Get Private Link Config](/ko/docs/api/sites/get-private-link): Returns the private link key configuration. Private links allow sharing analytics with a secret key without requiring authentication.
    - [Update Private Link Config](/ko/docs/api/sites/update-private-link): Generates or revokes a private link key for sharing analytics without authentication. Requires admin or owner role.
    - [Export PDF Report](/ko/docs/api/sites/export-pdf): Generates a downloadable PDF analytics report for a date range.
  - Imports
    - [List Imports](/ko/docs/api/imports/list): Returns all data imports for a site with their progress counts.
    - [Create Import](/ko/docs/api/imports/create): Starts a new data import from a supported platform.
    - [Upload Import Events](/ko/docs/api/imports/events): Uploads a batch of raw events to an in-progress import.
    - [Delete Import](/ko/docs/api/imports/delete): Deletes an import and all events it added. The import must be finished.
  - API Keys
    - [Create API Key](/ko/docs/api/api-keys/create): Programmatically create a new API key for your account.
    - [Create Organization API Key](/ko/docs/api/api-keys/create-org): Programmatically create an API key owned by an organization.
    - [List API Keys](/ko/docs/api/api-keys/list): List the API keys for your account or organization.
    - [Update API Key](/ko/docs/api/api-keys/update): Update an existing API key's name, enabled state, or expiry.
    - [Delete API Key](/ko/docs/api/api-keys/delete): Revoke an API key by its id.

  - **Guides**
  - [Automated Weekly Report](/pt/docs/api/weekly-report): Combine the overview and metric endpoints into a scheduled digest that summarizes last week's traffic, the week-over-week change, and your top pages and traffic sources.

  - [Build a Live Visitor Feed](/pt/docs/api/live-feed): Poll the live visitor count and the events endpoint to build a real-time activity stream — the foundation for a live dashboard, an internal "who's online" widget, or an alert when a key page gets traffic.

  - **Endpoints**
  - [Sending Events](/pt/docs/api/sending-events): Track pageviews, custom events, performance, and errors from any platform using the HTTP API.
  - Overview
    - [Get Overview](/pt/docs/api/overview/overview): Returns high-level analytics metrics for a site.
    - [Get Overview (Time Series)](/pt/docs/api/overview/time-series): Returns time-series analytics data broken down by configurable time buckets. Useful for charting trends over time.
    - [Get Metric](/pt/docs/api/overview/metric): Returns dimensional analytics data broken down by a specific parameter. Supports pagination.
    - [Get Page Titles](/pt/docs/api/overview/page-titles): Returns page-view metrics aggregated by HTML page title.
    - [Get Live Visitors](/pt/docs/api/overview/live-visitors): Returns the count of unique active visitors within the specified time window. Useful for displaying real-time visitor counts.
  - Sessions
    - [Get Sessions](/pt/docs/api/sessions/list): Returns a paginated list of sessions with their analytics data.
    - [Get Session](/pt/docs/api/sessions/get): Returns detailed information about a specific session including all events and pageviews.
    - [Get Session Locations](/pt/docs/api/sessions/locations): Returns aggregated session locations with coordinates for map visualization.
  - Session Replay
    - [Get Session Replays](/pt/docs/api/session-replay/list): Returns recorded session replays with metadata, newest first.
    - [Get Session Replay Events](/pt/docs/api/session-replay/events): Returns the rrweb events and metadata needed to reconstruct a session replay.
    - [Delete Session Replay](/pt/docs/api/session-replay/delete): Permanently deletes a session replay recording. Requires site write access.
  - Users
    - [Get Users](/pt/docs/api/users/list): Returns a paginated list of users with their analytics data. Supports filtering by identified users only.
    - [Get User Session Count](/pt/docs/api/users/session-count): Returns the number of sessions per day for a specific user. Useful for visualizing user engagement over time.
    - [Get User Info](/pt/docs/api/users/info): Returns detailed information about a specific user, including their profile traits and linked devices.
  - User Traits
    - [Get User Trait Keys](/pt/docs/api/user-traits/keys): Returns the known user trait keys with the number of users that have each.
    - [Get User Trait Values](/pt/docs/api/user-traits/values): Returns the distinct values for a given trait key, with user counts.
    - [Get Users by Trait](/pt/docs/api/user-traits/users): Returns users matching a specific trait key and value, with location and session metadata.
  - Events
    - [Get Events](/pt/docs/api/events/list): Returns a paginated list of events (pageviews, custom events, and outbound clicks).
    - [Get Event Names](/pt/docs/api/events/names): Returns a list of unique custom event names with their occurrence counts.
    - [Get Event Time Series](/pt/docs/api/events/time-series): Returns time-bucketed counts for the top custom events.
    - [Get Event Counts](/pt/docs/api/events/count): Returns time-bucketed event counts grouped by event type.
    - [Get Event Properties](/pt/docs/api/events/properties): Returns property key-value pairs for a specific event name with their occurrence counts.
    - [Get Outbound Links](/pt/docs/api/events/outbound): Returns a list of outbound link clicks with their occurrence counts.
  - Goals
    - [Get Goals](/pt/docs/api/goals/list): Returns a paginated list of goals with their conversion metrics.
    - [Get Goal Time Series](/pt/docs/api/goals/time-series): Returns goal conversions and conversion rate over time.
    - [Get Goal Sessions](/pt/docs/api/goals/sessions): Returns sessions that completed a specific goal. Useful for analyzing the behavior of converting users.
    - [Create Goal](/pt/docs/api/goals/create): Creates a new goal for tracking conversions.
    - [Update Goal](/pt/docs/api/goals/update): Updates an existing goal.
    - [Delete Goal](/pt/docs/api/goals/delete): Deletes a goal. This action cannot be undone.
  - Funnels
    - [Get Funnels](/pt/docs/api/funnels/list): Returns all saved funnels for a site.
    - [Analyze Funnel](/pt/docs/api/funnels/analyze): Analyzes a funnel and returns step-by-step conversion data. Sessions must complete steps in order (step 2 must occur after step 1, etc.).
    - [Get Funnel Step Sessions](/pt/docs/api/funnels/step-sessions): Returns sessions that either reached or dropped off at a specific funnel step. Useful for analyzing user behavior at each stage.
    - [Create Funnel](/pt/docs/api/funnels/create): Creates or updates a saved funnel. If `reportId` is provided, updates the existing funnel.
    - [Delete Funnel](/pt/docs/api/funnels/delete): Deletes a saved funnel. This action cannot be undone.
  - Performance
    - [Get Performance Overview](/pt/docs/api/performance/overview): Returns aggregate performance metrics with percentile breakdowns for all Core Web Vitals.
    - [Get Performance Time Series](/pt/docs/api/performance/time-series): Returns performance metrics over time, broken down by configurable time buckets. Useful for charting performance trends.
    - [Get Performance by Dimension](/pt/docs/api/performance/by-dimension): Returns performance metrics broken down by a specific dimension (page, country, browser, etc.). Useful for identifying performance issues on specific pages or for specific user segments.
  - Errors
    - [Get Error Names](/pt/docs/api/errors/names): Returns a list of unique error messages with occurrence counts and affected session counts.
    - [Get Error Events](/pt/docs/api/errors/events): Returns individual error occurrences for a specific error message, with full context including stack traces.
    - [Get Error Time Series](/pt/docs/api/errors/time-series): Returns error occurrence counts over time for a specific error message. Useful for tracking error trends and identifying when issues started.
  - Bots
    - [Get Bot Overview](/pt/docs/api/bots/overview): Returns aggregate bot-traffic metrics with a breakdown by detection layer.
    - [Get Bot Time Series](/pt/docs/api/bots/time-series): Returns bot request counts over time.
    - [Get Bots by Dimension](/pt/docs/api/bots/by-dimension): Returns bot requests broken down by a dimension.
  - Insights
    - [Get Retention](/pt/docs/api/insights/retention): Returns cohort-based retention analysis data. Users are grouped into cohorts based on their first visit, and retention is tracked over subsequent time periods.
    - [Get Journeys](/pt/docs/api/insights/journeys): Returns the most common page navigation paths (user journeys) within sessions. Useful for understanding how users navigate through your site.

  - **Management**
  - Organizations
    - [Get My Organizations](/pt/docs/api/organizations/list): Returns all organizations the authenticated user is a member of, including all members for each organization. Excludes subscription and billing information. Supports both session cookies and API key (Bearer token) authentication.
    - [Get Organization Sites](/pt/docs/api/organizations/sites): Returns all sites in an organization the caller can access, with usage and subscription info.
    - [Create Site](/pt/docs/api/organizations/create-site): Creates a new site within an organization. Requires admin or owner role in the organization.
    - [Get Organization Members](/pt/docs/api/organizations/members): Returns all members of an organization with their user details and roles. Requires membership in the organization.
    - [Add Organization Member](/pt/docs/api/organizations/add-member): Adds a user to an organization with a specified role. The user must already exist in the system. Requires admin or owner role in the organization.
    - [Invite Member](/pt/docs/api/organizations/invite-member): Send an organization invitation to a user by email.
    - [Remove Member](/pt/docs/api/organizations/remove-member): Remove a member from an organization.
    - [Update Member Role](/pt/docs/api/organizations/update-member-role): Change an organization member's role.
    - [Get Organization Event Count](/pt/docs/api/organizations/event-count): Returns daily event usage counts across an organization's sites.
  - Teams
    - [Get Teams](/pt/docs/api/teams/list): Returns the teams in an organization, with their members and accessible sites.
    - [Create Team](/pt/docs/api/teams/create): Creates a team in an organization. Requires admin/owner role.
    - [Update Team](/pt/docs/api/teams/update): Updates a team's name, members, or site access. Requires admin/owner role.
    - [Delete Team](/pt/docs/api/teams/delete): Deletes a team. Requires admin/owner role.
  - Sites
    - [Get Site](/pt/docs/api/sites/get): Returns detailed information about a specific site including its configuration.
    - [Get Site Has Data](/pt/docs/api/sites/has-data): Returns whether the site has received any analytics events.
    - [Get Site Public Status](/pt/docs/api/sites/is-public): Returns whether the site's analytics are publicly accessible.
    - [Delete Site](/pt/docs/api/sites/delete): Permanently deletes a site and all its associated data. This action cannot be undone. Requires admin or owner role.
    - [Update Site Config](/pt/docs/api/sites/update-config): Updates site configuration settings. All fields are optional - only include the fields you want to update. Requires admin or owner role.
    - [Get Excluded IPs](/pt/docs/api/sites/excluded-ips): Returns the list of IP addresses and CIDR ranges that are excluded from tracking.
    - [Get Excluded Countries](/pt/docs/api/sites/excluded-countries): Returns the list of country codes that are excluded from tracking.
    - [Get Excluded Paths](/pt/docs/api/sites/excluded-paths): Returns the list of URL paths excluded from analytics.
    - [Get Excluded Hostnames](/pt/docs/api/sites/excluded-hostnames): Returns the list of hostnames excluded from analytics.
    - [Get Excluded User Agents](/pt/docs/api/sites/excluded-user-agents): Returns the list of user-agent patterns excluded from analytics.
    - [Get Private Link Config](/pt/docs/api/sites/get-private-link): Returns the private link key configuration. Private links allow sharing analytics with a secret key without requiring authentication.
    - [Update Private Link Config](/pt/docs/api/sites/update-private-link): Generates or revokes a private link key for sharing analytics without authentication. Requires admin or owner role.
    - [Export PDF Report](/pt/docs/api/sites/export-pdf): Generates a downloadable PDF analytics report for a date range.
  - Imports
    - [List Imports](/pt/docs/api/imports/list): Returns all data imports for a site with their progress counts.
    - [Create Import](/pt/docs/api/imports/create): Starts a new data import from a supported platform.
    - [Upload Import Events](/pt/docs/api/imports/events): Uploads a batch of raw events to an in-progress import.
    - [Delete Import](/pt/docs/api/imports/delete): Deletes an import and all events it added. The import must be finished.
  - API Keys
    - [Create API Key](/pt/docs/api/api-keys/create): Programmatically create a new API key for your account.
    - [Create Organization API Key](/pt/docs/api/api-keys/create-org): Programmatically create an API key owned by an organization.
    - [List API Keys](/pt/docs/api/api-keys/list): List the API keys for your account or organization.
    - [Update API Key](/pt/docs/api/api-keys/update): Update an existing API key's name, enabled state, or expiry.
    - [Delete API Key](/pt/docs/api/api-keys/delete): Revoke an API key by its id.

  - [Build a Live Visitor Feed](/ja/docs/api/live-feed): Poll the live visitor count and the events endpoint to build a real-time activity stream — the foundation for a live dashboard, an internal "who's online" widget, or an alert when a key page gets traffic.

  - **Endpoints**
  - [Sending Events](/ja/docs/api/sending-events): Track pageviews, custom events, performance, and errors from any platform using the HTTP API.
  - Overview
    - [Get Overview](/ja/docs/api/overview/overview): Returns high-level analytics metrics for a site.
    - [Get Overview (Time Series)](/ja/docs/api/overview/time-series): Returns time-series analytics data broken down by configurable time buckets. Useful for charting trends over time.
    - [Get Metric](/ja/docs/api/overview/metric): Returns dimensional analytics data broken down by a specific parameter. Supports pagination.
    - [Get Page Titles](/ja/docs/api/overview/page-titles): Returns page-view metrics aggregated by HTML page title.
    - [Get Live Visitors](/ja/docs/api/overview/live-visitors): Returns the count of unique active visitors within the specified time window. Useful for displaying real-time visitor counts.
  - Sessions
    - [Get Sessions](/ja/docs/api/sessions/list): Returns a paginated list of sessions with their analytics data.
    - [Get Session](/ja/docs/api/sessions/get): Returns detailed information about a specific session including all events and pageviews.
    - [Get Session Locations](/ja/docs/api/sessions/locations): Returns aggregated session locations with coordinates for map visualization.
  - Session Replay
    - [Get Session Replays](/ja/docs/api/session-replay/list): Returns recorded session replays with metadata, newest first.
    - [Get Session Replay Events](/ja/docs/api/session-replay/events): Returns the rrweb events and metadata needed to reconstruct a session replay.
    - [Delete Session Replay](/ja/docs/api/session-replay/delete): Permanently deletes a session replay recording. Requires site write access.
  - Users
    - [Get Users](/ja/docs/api/users/list): Returns a paginated list of users with their analytics data. Supports filtering by identified users only.
    - [Get User Session Count](/ja/docs/api/users/session-count): Returns the number of sessions per day for a specific user. Useful for visualizing user engagement over time.
    - [Get User Info](/ja/docs/api/users/info): Returns detailed information about a specific user, including their profile traits and linked devices.
  - User Traits
    - [Get User Trait Keys](/ja/docs/api/user-traits/keys): Returns the known user trait keys with the number of users that have each.
    - [Get User Trait Values](/ja/docs/api/user-traits/values): Returns the distinct values for a given trait key, with user counts.
    - [Get Users by Trait](/ja/docs/api/user-traits/users): Returns users matching a specific trait key and value, with location and session metadata.
  - Events
    - [Get Events](/ja/docs/api/events/list): Returns a paginated list of events (pageviews, custom events, and outbound clicks).
    - [Get Event Names](/ja/docs/api/events/names): Returns a list of unique custom event names with their occurrence counts.
    - [Get Event Time Series](/ja/docs/api/events/time-series): Returns time-bucketed counts for the top custom events.
    - [Get Event Counts](/ja/docs/api/events/count): Returns time-bucketed event counts grouped by event type.
    - [Get Event Properties](/ja/docs/api/events/properties): Returns property key-value pairs for a specific event name with their occurrence counts.
    - [Get Outbound Links](/ja/docs/api/events/outbound): Returns a list of outbound link clicks with their occurrence counts.
  - Goals
    - [Get Goals](/ja/docs/api/goals/list): Returns a paginated list of goals with their conversion metrics.
    - [Get Goal Time Series](/ja/docs/api/goals/time-series): Returns goal conversions and conversion rate over time.
    - [Get Goal Sessions](/ja/docs/api/goals/sessions): Returns sessions that completed a specific goal. Useful for analyzing the behavior of converting users.
    - [Create Goal](/ja/docs/api/goals/create): Creates a new goal for tracking conversions.
    - [Update Goal](/ja/docs/api/goals/update): Updates an existing goal.
    - [Delete Goal](/ja/docs/api/goals/delete): Deletes a goal. This action cannot be undone.
  - Funnels
    - [Get Funnels](/ja/docs/api/funnels/list): Returns all saved funnels for a site.
    - [Analyze Funnel](/ja/docs/api/funnels/analyze): Analyzes a funnel and returns step-by-step conversion data. Sessions must complete steps in order (step 2 must occur after step 1, etc.).
    - [Get Funnel Step Sessions](/ja/docs/api/funnels/step-sessions): Returns sessions that either reached or dropped off at a specific funnel step. Useful for analyzing user behavior at each stage.
    - [Create Funnel](/ja/docs/api/funnels/create): Creates or updates a saved funnel. If `reportId` is provided, updates the existing funnel.
    - [Delete Funnel](/ja/docs/api/funnels/delete): Deletes a saved funnel. This action cannot be undone.
  - Performance
    - [Get Performance Overview](/ja/docs/api/performance/overview): Returns aggregate performance metrics with percentile breakdowns for all Core Web Vitals.
    - [Get Performance Time Series](/ja/docs/api/performance/time-series): Returns performance metrics over time, broken down by configurable time buckets. Useful for charting performance trends.
    - [Get Performance by Dimension](/ja/docs/api/performance/by-dimension): Returns performance metrics broken down by a specific dimension (page, country, browser, etc.). Useful for identifying performance issues on specific pages or for specific user segments.
  - Errors
    - [Get Error Names](/ja/docs/api/errors/names): Returns a list of unique error messages with occurrence counts and affected session counts.
    - [Get Error Events](/ja/docs/api/errors/events): Returns individual error occurrences for a specific error message, with full context including stack traces.
    - [Get Error Time Series](/ja/docs/api/errors/time-series): Returns error occurrence counts over time for a specific error message. Useful for tracking error trends and identifying when issues started.
  - Bots
    - [Get Bot Overview](/ja/docs/api/bots/overview): Returns aggregate bot-traffic metrics with a breakdown by detection layer.
    - [Get Bot Time Series](/ja/docs/api/bots/time-series): Returns bot request counts over time.
    - [Get Bots by Dimension](/ja/docs/api/bots/by-dimension): Returns bot requests broken down by a dimension.
  - Insights
    - [Get Retention](/ja/docs/api/insights/retention): Returns cohort-based retention analysis data. Users are grouped into cohorts based on their first visit, and retention is tracked over subsequent time periods.
    - [Get Journeys](/ja/docs/api/insights/journeys): Returns the most common page navigation paths (user journeys) within sessions. Useful for understanding how users navigate through your site.

  - **Management**
  - Organizations
    - [Get My Organizations](/ja/docs/api/organizations/list): Returns all organizations the authenticated user is a member of, including all members for each organization. Excludes subscription and billing information. Supports both session cookies and API key (Bearer token) authentication.
    - [Get Organization Sites](/ja/docs/api/organizations/sites): Returns all sites in an organization the caller can access, with usage and subscription info.
    - [Create Site](/ja/docs/api/organizations/create-site): Creates a new site within an organization. Requires admin or owner role in the organization.
    - [Get Organization Members](/ja/docs/api/organizations/members): Returns all members of an organization with their user details and roles. Requires membership in the organization.
    - [Add Organization Member](/ja/docs/api/organizations/add-member): Adds a user to an organization with a specified role. The user must already exist in the system. Requires admin or owner role in the organization.
    - [Invite Member](/ja/docs/api/organizations/invite-member): Send an organization invitation to a user by email.
    - [Remove Member](/ja/docs/api/organizations/remove-member): Remove a member from an organization.
    - [Update Member Role](/ja/docs/api/organizations/update-member-role): Change an organization member's role.
    - [Get Organization Event Count](/ja/docs/api/organizations/event-count): Returns daily event usage counts across an organization's sites.
  - Teams
    - [Get Teams](/ja/docs/api/teams/list): Returns the teams in an organization, with their members and accessible sites.
    - [Create Team](/ja/docs/api/teams/create): Creates a team in an organization. Requires admin/owner role.
    - [Update Team](/ja/docs/api/teams/update): Updates a team's name, members, or site access. Requires admin/owner role.
    - [Delete Team](/ja/docs/api/teams/delete): Deletes a team. Requires admin/owner role.
  - Sites
    - [Get Site](/ja/docs/api/sites/get): Returns detailed information about a specific site including its configuration.
    - [Get Site Has Data](/ja/docs/api/sites/has-data): Returns whether the site has received any analytics events.
    - [Get Site Public Status](/ja/docs/api/sites/is-public): Returns whether the site's analytics are publicly accessible.
    - [Delete Site](/ja/docs/api/sites/delete): Permanently deletes a site and all its associated data. This action cannot be undone. Requires admin or owner role.
    - [Update Site Config](/ja/docs/api/sites/update-config): Updates site configuration settings. All fields are optional - only include the fields you want to update. Requires admin or owner role.
    - [Get Excluded IPs](/ja/docs/api/sites/excluded-ips): Returns the list of IP addresses and CIDR ranges that are excluded from tracking.
    - [Get Excluded Countries](/ja/docs/api/sites/excluded-countries): Returns the list of country codes that are excluded from tracking.
    - [Get Excluded Paths](/ja/docs/api/sites/excluded-paths): Returns the list of URL paths excluded from analytics.
    - [Get Excluded Hostnames](/ja/docs/api/sites/excluded-hostnames): Returns the list of hostnames excluded from analytics.
    - [Get Excluded User Agents](/ja/docs/api/sites/excluded-user-agents): Returns the list of user-agent patterns excluded from analytics.
    - [Get Private Link Config](/ja/docs/api/sites/get-private-link): Returns the private link key configuration. Private links allow sharing analytics with a secret key without requiring authentication.
    - [Update Private Link Config](/ja/docs/api/sites/update-private-link): Generates or revokes a private link key for sharing analytics without authentication. Requires admin or owner role.
    - [Export PDF Report](/ja/docs/api/sites/export-pdf): Generates a downloadable PDF analytics report for a date range.
  - Imports
    - [List Imports](/ja/docs/api/imports/list): Returns all data imports for a site with their progress counts.
    - [Create Import](/ja/docs/api/imports/create): Starts a new data import from a supported platform.
    - [Upload Import Events](/ja/docs/api/imports/events): Uploads a batch of raw events to an in-progress import.
    - [Delete Import](/ja/docs/api/imports/delete): Deletes an import and all events it added. The import must be finished.
  - API Keys
    - [Create API Key](/ja/docs/api/api-keys/create): Programmatically create a new API key for your account.
    - [Create Organization API Key](/ja/docs/api/api-keys/create-org): Programmatically create an API key owned by an organization.
    - [List API Keys](/ja/docs/api/api-keys/list): List the API keys for your account or organization.
    - [Update API Key](/ja/docs/api/api-keys/update): Update an existing API key's name, enabled state, or expiry.
    - [Delete API Key](/ja/docs/api/api-keys/delete): Revoke an API key by its id.
